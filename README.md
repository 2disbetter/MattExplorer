# MattExplorer
A fast, lightweight file manager for Omarchy (Arch Linux + Hyprland), in the spirit of Windows File Explorer and File Pilot: left sidebar with places, pinned folders and devices; tabbed browsing on the right with icon, list and details views.

Written in C++23 with **no dependencies** beyond libc. It talks to  Wayland over the wire protocol, renders on the CPU, and parse fonts, keymaps, and images internally.
